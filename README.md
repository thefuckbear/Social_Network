# 微博舆论话题数据分析与社会网络分析

本项目是“计算传播：社会网络分析”课程研究成果，围绕“小米 SU7 智能驾驶事故”相关微博讨论，结合公开数据采集、文本分析、社会网络分析和 Gephi 可视化，考察事故舆情中不同账号、观点社群与互动关系的结构特征。

课程项目周期为 2026 年 5 月至 7 月。新版互动网络以 2025 年 4 月 1 日至 12 日的事故发酵窗口为核心采集范围，并于 2026 年 7 月完成数据更新、网络指标重算和论文整理。

## 研究问题

项目主要关注以下问题：

1. 事故舆情中有哪些主要观点社群？
2. 评论、回复、转发和提及关系如何连接不同社群？
3. 哪些账号位于传播网络的关键位置？
4. 不同账号类型、观点框架和情绪倾向之间呈现怎样的结构关系？
5. 舆情从事故事实、责任追问扩展到品牌信任、消费权益和行业监管时，关键传播路径如何形成？

## 研究方法

### 数据采集与整理

- 使用 Python 编写微博互动关系采集脚本。
- 一级评论边表示“评论者 → 原帖作者”。
- 楼中楼回复边表示“回复者 → 被回复评论者”。
- 转发边表示“转发者 → 被转发账号”。
- 提及边表示“发帖或评论账号 → 被提及账号”。
- 使用 pandas 完成表格整理、账号去重和节点/边表生成。

### 社会网络分析

- 使用 NetworkX、SciPy 与 R 对互动网络进行统计。
- 计算 PageRank、互动中心性、连入/连出强度和传播度。
- 使用 Gephi 观察社群关联、关键节点、桥梁账号和跨社群互动。
- 输出节点表与边表，便于在 Gephi 中继续调整布局、筛选和可视化。

项目采用的传播度公式为：

```text
传播度 = 0.45 × 标准化 PageRank
       + 0.35 × 标准化互动中心性
       + 0.15 × 标准化注意力连入强度
       + 0.05 × 标准化加权互动总量
```

粉丝量仅作为账号背景字段，不参与传播度计算。

### 文本与情绪分析

- 使用 jieba、pandas 和词典法进行中文文本统计。
- 情绪判断采用“极性词 + 程度副词 + 否定词”的课程级分析框架。
- 根据事故舆情场景补充爆燃、伤亡、质疑、问责、家属、诉讼和监管等领域词。
- 将“观点社群”和“情绪倾向”作为两个不同变量处理，避免把议题框架直接等同于情绪极性。

## 查看交互式传播网络

进入以下目录：

```text
小米SU7爆燃事件微博话题/新数据(以此为准)/05_交互可视化html
```

不要直接双击 `index.html`。建议在该目录启动本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

交互页面中，节点颜色表示观点社群，节点大小表示传播度；页面同时读取 `nodes.json`、`edges.json` 和 `summary.json`。

## 使用 Gephi 查看网络

1. 打开 Gephi。
2. 导入 `02_Gephi网络表/04_新采集互动节点表.csv` 作为节点表。
3. 导入 `02_Gephi网络表/05_新采集互动边表.csv` 作为边表。
4. 按“观点社群”设置节点颜色，按“传播度”设置节点大小。
5. 根据研究目的选择 ForceAtlas 2 等布局，并筛选评论、回复、转发或提及关系。

`08_Gephi项目` 中保留了旧工程与新版表格导入说明。

## 运行分析脚本

主要 Python 依赖包括：

```bash
pip install pandas numpy scipy networkx matplotlib jieba lxml openpyxl
```

分析脚本位于：

```text
小米SU7爆燃事件微博话题/新数据(以此为准)/06_脚本scripts
```

- `12_weibo_interaction_crawler.py`：采集评论、楼中楼回复和转发关系。
- `13_network_analysis_visualization.py`：生成网络指标、图表和交互数据。
- `14_text_sentiment_stats.py`：完成文本、词频和情绪统计。
- `R_network_stats_作业1.R`：R 网络统计。
- `R_text_stats_作业2.R`：R 文本统计与绘图。

采集脚本依赖微博接口及有效会话状态。接口可能变化，也应遵守平台规则、访问频率限制和个人信息保护要求。若只想查看结果，无需重新运行爬虫，直接使用项目内现成的数据、图表和交互页面即可。

## 研究边界

- 本项目是课程研究，不是对事故责任的法律认定。
- 数据来自特定关键词、时间窗口与公开页面，不能代表微博全部用户或完整社会舆论。
- 删除、不可见、接口未返回的内容不在样本中。
- “商业亲和线索”是根据公开可观测特征自动生成的代理指标，仅用于课程级探索，不能据此认定账号存在真实商业关系。
- 新增账号的观点社群、情绪和商业亲和字段包含规则辅助初分，适合探索性分析，正式引用时应继续进行人工抽样复核。
- 数据仅用于学习和研究。公开展示时应注意隐私、平台条款与研究伦理。
